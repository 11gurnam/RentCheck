# Phase 25 — address dropdowns and saved maps

The Add place form has linked state/city dropdowns for all 36 states/union territories and 6,998 city/town names. Changing a state clears the city, PIN and coordinates. The bundled India-only extract is derived from [GeoNames cities1000/admin1](https://download.geonames.org/export/dump/) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), downloaded 13 October 2026. Source hashes are in `src/features/addresses/data-source.json`; regeneration uses `scripts/generate-india-addresses.mjs` after downloading/extracting the two official files into ignored `work/geonames`. It is a community gazetteer, not an exhaustive official settlement registry. Address lookup can supply a city missing from the dropdown.

The user ultimately requested a provider requiring no account setup. Leaflet/OpenStreetMap provides a click-to-move pin; “Use my location” requests browser permission only on click. Photon provides explicit address searches/reverse lookups. Selecting a returned address fills its state, city, locality and valid six-digit PIN when supplied. Reverse lookup preserves the pin selected by the user. PIN remains editable and is never inferred as one code for an entire city.

`202610130003_contribution_locations.sql` saves PIN and consented coordinates in the same transaction as property creation. Existing records are preserved. Direct coordinate mutations remain denied; the original authorized contribution function and record-mode checks are retained. Coordinates are omitted unless “Show this pin on the public property map” is checked. Pins appear on the property profile, map page, discovery card link and comparison; Google Maps links open the chosen coordinates without an API key. Existing properties without supplied pins retain an honest empty state.

Check: Add place → choose state/city → Choose location on map → Use my location or click the map → Fill address from pin → select an address match → check PIN/address → confirm public sharing → save. Reload the property, inspect the map page and compare it with another place. Location denial or lookup outage still permits manual address/PIN entry. Do not use a current-device pin if it does not mark the property.

External service configuration is optional: `ADDRESS_LOOKUP_URL` changes the Photon-compatible server; `NEXT_PUBLIC_MAP_TILE_URL` changes the tile provider. The public Photon server accepts reasonable usage but has no availability guarantee. Lookups are explicit, authenticated, bounded to India and limited per user per runtime instance; tile loading retains OpenStreetMap attribution. Higher traffic requires a suitable hosted/self-hosted provider. No paid service or Google billing was configured.

Validation includes unit tests for state coverage, postcode absence and foreign/invalid coordinates; integration tests for atomic PIN/pin persistence and denied direct edits; and browser tests for city resets, permission-triggered current location, reverse lookup/PIN fill, explicit sharing and persisted map links. Browser geolocation/provider replies are controlled fixtures; a separate real Photon request returned HTTP 200 for Jaipur.
